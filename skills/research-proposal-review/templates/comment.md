# Comment format

In the reply, one block per comment, ordered by severity:

```
**N.** <Section of the doc>, en "<literal anchor copied from the doc>"
> <The comment, in B1 English, as it will be posted.>
```

The section is only to locate the anchor; it is not part of the comment. The anchor is text
the author can find with search.

After the list:

- One line per comment that overlaps another, saying which one stays.
- One line with the comments that can be dropped when the author wants fewer, by number.
- Every fact a comment states that could not be verified, with what would verify it.

Before the list, when the user asked for it or the doc is new to them: what the doc proposes
in a few lines and which services it touches.
